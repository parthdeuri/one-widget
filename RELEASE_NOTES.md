## one-widget v0.1

First release.

### Widgets
- **Digital clock**: 12/24-hour time, optional seconds, date above or below the time, six date formats, next alarm.
- **Analog clock**: customizable face, ticks, hands and numbers.
- **Calendar**: month grid with navigation, Monday-first option, event dots (needs Calendar permission).
- **Clock + calendar**: both in one widget, side by side or stacked, either first, each side opening its own app.
- **Countdown**: days until (or since) a date, with your own label.

### Customization
- Colours for every element, text sizes, tap-to-open-any-app.
- Backgrounds: colour or gradient, opacity (down to fully transparent), rounded corners, patterns, and your own image.
- Eight theme presets: Dark, Light, Midnight, Ocean, Sunset, Forest, Lavender, Cherry blossom.
- All widgets are resizable.
- App theme: Normal (default) or Sakura.

### Install
Download `one-widget-v0.1.apk` below and install it (allow installs from unknown sources). Builds signed with the project's key install over each other as updates.
